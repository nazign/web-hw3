# 실습과제 #3 : 살아 움직이는 영화 보드
- 이름 / 학번 :
- 사이트 주소 : https://binbin-ai.github.io/web-hw3/
- 사용한 API : TMDB(포스터, 영화 정보), KOBIS(일별 박스오피스, 기준일 2026-10-25)
 
## 구현 항목 체크(기능 체크표)
| 요구사항 | 상태 | 한 줄 메모 |
|---|---|---|
| 1. 렌더링 | ✓ | 배열 list로 카드 렌더링 |
| 2. 검색| ✓ | 배열 내부 객체 반환값 |
| 3. 정렬 3종 | ✓ | 라디오 박스 값 기준 정렬 |
| 4. 필터와 찜 | ✓ | 조건에 맞게 렌더링 하기위한 배열 생성 |
| 5. 상세 | ✓ | 상세 대화 상자을 열어 줌 (반환값 x) |
| 6. 빈 결과 | ✓ | 찜 클릭 제외 |
| 7. 코드 품질 | ✓ | 함수마다 주석으로 입력 -> 출력을 적어 둠 |
| 8. 인라인 이벤트 속성 없음, 콘솔 오류 0 | ✓ |확인 결과 이상 무|

 
## 어려웠던 점 3가지와 해결
- 1. 카드 10장이 보이지 않음 -> 중괄호와 알파벳 오타를 확인하여 해결

- 2. 찜 개수가 늘어나지 않음 -> 기존의 함수를 지우고 새 내용을 적어 넣어 해결

- 3. 상세 상자에서 닫기를 눌러도 닫히지 않음 -> html의 id가 clseDetail로 되어 있는 것을 확인 후 해결
 
## 참고한 자료 (교재 절, MDN 페이지 제목, 검색어)
- 검색어 : .splice의 뜻
